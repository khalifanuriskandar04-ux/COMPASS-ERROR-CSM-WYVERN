📍 COMMON OBJECTS — TRUE BEARING REFERENCE
OBJECT OBSERVATION
Compass Error = True Bearing − Compass Bearing.
🧭 COMPASS ERROR THEORY
Compass Error = Deviation + Variation
Magnetic (M) = Compass (C) + Deviation
True (T) = Magnetic (M) + Variation
True (T) = Compass (C) + Compass Error

Sign convention: East is positive (+), West is negative (−). Bearings are normalized to 000°–360°.

Object observation: if a fixed object's true bearing is known, Compass Error = True Bearing − Observed Compass Bearing. The sign of the result indicates E/W.

⚠ NAVIGATION NOTE

Use the vessel's approved deviation card and the correct charted magnetic variation for the position/date. This calculator is a navigation aid and does not replace approved compass checks, nautical charts, ECDIS procedures, or the vessel's SMS.
